# Environmental Systems and Societies specialist: supplementary knowledge documents

## What this folder contains

Four documents that tell the Environmental Systems and Societies (ESS) specialist how
to think, which answer patterns to use, how to answer within the website pilot's
rules (including the overlap with Biology and Geography), and what good replies look
like. They are written for an IB Diploma ESS tutor whose students are 16 to 19 years
old.

## Status

Proposed supplement, not part of the pinned knowledge-base bundle; adding these to
the bundle would change its SHA-256 and requires a separately reviewed bundle
version.

The specialist's own master prompt and knowledge base are proprietary and were not
visible when these documents were written. These documents never override them:
each file's front matter says that the master prompt and knowledge base win wherever
they disagree, and any conflict should be reported to the maintainers rather than
resolved silently. The slug `ess` is marked provisional in `agents/agents.json` and
must be checked against the real knowledge-base folder name.

## Load order

1. ESS master prompt (proprietary).
2. The ESS specialist's own knowledge base (the pinned bundle).
3. These documents, in file order: 01, 02, 03, 04.

## Design notes

- Written to agree with version 0.1.1 of the shared answering document. If that
  document changes, re-check file 03 and the examples in file 04 against it.
- The pilot runs with no tools. File 03 asks for the formula version, defined
  symbols, explicit substitution and units on every result, so that planned
  deterministic checks of arithmetic and conversions can follow each step.
- The overlap policy matches the Biology folder's version from the other side: the
  router clarifies ambiguous requests; once routed, ESS answers with the systems
  approach, value systems, sustainability and management, and names Biology
  (mechanisms) or Geography when they suit part of the question better.
- All calculations and equation balances were recomputed independently.
- No URLs, citations, official criterion names, weightings, durations or mark totals
  are stated as fact.

## Facts to verify

Check these against the current IB ESS guide and the specialist's own knowledge base
before any of this content moves into a reviewed bundle.

1. **Guide edition and levels.** The ESS guide was recently revised. No topic
   numbers, theme names, first-assessment year, paper structure, durations,
   weightings or mark totals are stated. File 03 deliberately does not say whether
   ESS is offered at SL only or at both SL and HL; confirm before adding any level
   statement.
2. **Diploma group status.** File 01 calls ESS interdisciplinary (as the roster
   does) without saying which subject groups it satisfies.
3. **Multiple choice.** File 02 says whether ESS external assessment uses
   multiple-choice items is not stated here (verify against the current IB subject
   guide).
4. **Environmental value systems terminology.** File 01 uses the ecocentric,
   anthropocentric and technocentric spectrum and tells students to check their
   course's exact terms. Confirm the current guide's categories.
5. **Simpson's index form.** File 04 uses the reciprocal form
   D = N(N − 1) / Σn(n − 1) as "the form commonly used in ESS" and mentions
   1 − Σn(n − 1) / N(N − 1) as an alternative; file 03 tells the specialist to state
   the form it uses. Confirm the course's form.
6. **Lincoln index notation and assumptions** (M, C, R) in files 02 and 04.
7. **Pollution management model.** File 01 and example 2 in file 04 describe three
   levels (changing the activity, controlling release, clean-up and restoration) in
   paraphrase. Confirm the course's wording.
8. **Generalisations.** The "about 10 %" trophic transfer efficiency (labelled a
   rough generalisation) and the "70 divided by the growth rate" doubling-time
   approximation in file 01.
9. **Definitions** of transfers and transformations, and of open, closed and
   isolated systems, in file 01.
10. **Climate statements.** Files 03 and 04 present as mainstream science that human
    activities are increasing greenhouse gas concentrations and that recent warming
    is mainly caused by human emissions. Confirm the wording matches the master
    prompt's approach to contested topics.
11. **Internal assessment.** Official criterion names, weightings and length limits
    are not stated. The rubric in file 02 is illustrative, not the official IB
    criteria.
12. **Command terms.** File 02 gives paraphrases, including "define", "list" and
    "to what extent"; check against the official definitions.
13. **Overlap policy wording** in file 03. Confirm it matches the router's
    clarification behaviour and the Biology and Geography specialists' own rules.
14. **Neutrality and graded-homework rules** in file 03 are proposals. Confirm they
    match the master prompt.
15. **Sources line.** The sources lines in file 04 show content only; the exact
    format must come from the master prompt.
16. **Slug.** `ess` is provisional in the roster.
